# <i-bxs-balloon />Loon 配置

::: tip
<i-bxs-balloon />Loon 需要外区账号，且购买后才能安装；[<i-fa6-solid-magnifying-glass-location />](https://app.sensortower.com/overview/1373567447)<br>
如果你对如何获取 <i-bxs-balloon />Loon 感到疑惑，推荐 iOS 用户使用 [Sing-box](/proxies/singbox) 方案。
:::

1. 安装 <i-bxs-balloon />Loon：
    - 请自行寻找安装方法
    - 请尽量不要在 UsagiPass 用户群寻求安装帮助，如对安装有困难推荐查看 [Sing-box](/proxies/singbox) 方案
2. 添加 UsagiPass 节点
    - [一键导入 <i-bxs-balloon />](loon://import?sub=https%3a%2f%2fdxpass.turou.fun%2fUsagiPass.txt)
    - 或在 <i-bxs-balloon />Loon 的 配置 - 所有节点 中，点击右上角加号，添加一个订阅：https://dxpass.turou.fun/UsagiPass.txt
3. 添加 UsagiPass 插件
    - [一键导入 <i-bxs-balloon />](loon://import?plugin=https%3a%2f%2fdxpass.turou.fun%2fUsagiPass.plugin)
    - 或在 <i-bxs-balloon />Loon 的 配置 - 插件 中，添加一个插件：https://dxpass.turou.fun/UsagiPass.plugin
4. **回到 仪表 页面，点击右上角开关，<i-bxs-balloon />Loon成功启动后即可生效！**
